# Project Skills

This folder records the skills/tools DialedIN uses during development. Some entries are real Codex skills copied locally for reference; others are project tool notes.

## Real Codex Skills Copied For Reference

- `browser-control-in-app-browser`: visual app testing, clicking through flows, screenshots, and mobile viewport QA.
- `sites-building`: optional hosted site/deployment workflow support.
- `visualize`: optional flow/layout prototyping.
- `imagegen`: optional app icon, splash, or visual asset generation.

## Tool/Stack Notes

- `sites-design-picker`: optional design-selection tool, not a normal local skill.
- `frontend-stack`: Next.js, React/TypeScript, CSS, and browser file input APIs used for Checkpoint 14 implementation.

The active implementation plan also lists these under Checkpoint 14 in `docs/plan.md`, with the matching architecture note in `docs/spec.md`.
