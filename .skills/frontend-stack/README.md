# Frontend Stack

These are project technologies, not Codex skills to install.

- Next.js: app structure, routing, metadata, manifest/PWA support, typecheck, and production build.
- React/TypeScript: chat state, upload interactions, typed API payloads, and UI behavior.
- CSS: responsive layout, mobile safe areas, touch targets, sticky composer, and desktop compatibility.
- Browser file input APIs: photo/video attachment, camera/library selection, and local file upload behavior.

For Checkpoint 14, verify frontend changes with `npm run typecheck`, `npm run build`, and browser/mobile visual testing.
